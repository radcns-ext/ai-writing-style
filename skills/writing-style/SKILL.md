# writing-style — 커밋 메시지·주석 문체

코드에 남기는 글은 두 종류다. 커밋 메시지와 주석. 둘 다 목적은 같다 — **나중에 이걸 다시 만난 사람이 "왜" 를 아는 것.** "무엇" 은 diff 와 코드가 이미 말한다. 기계가 요약한 티가 나지 않게 쓴다.

---

## 1. 커밋 메시지

| 하지 말 것 | 대신 |
|---|---|
| `[Feat]` `[Fix]` 같은 태그 (프로젝트가 이미 쓰고 있지 않다면) | 그냥 문장으로 시작 |
| 엠대시 `—` 로 제목 뒤에 부연 붙이기 | 부연이 필요하면 본문으로 내리거나 버린다 |
| 제목 길이를 매번 비슷하게 맞추기 | 짧으면 짧은 대로 둔다. 8자짜리 제목도 좋은 제목이다 |
| 모든 커밋에 본문 달기 | 제목만으로 충분하면 제목만 쓴다 |
| 본문을 항상 불릿으로 나열 | 두세 문장 평문이 기본. 항목이 실제로 여럿일 때만 불릿 |
| "~하도록 수정", "~문제 수정" 반복 | 매번 다르게. 무슨 일이 있었는지 그대로 쓴다 |
| 개조식 종결("추가.", "마련.")로 통일 | 평서문과 섞어 쓴다 |
| `검증: 148/148` 같은 정형 라인 | 테스트 수치는 대개 커밋에 남길 필요가 없다 |
| AI 도구 푸터(`Co-Authored-By`, `Claude-Session`, `Generated with`) | 넣지 않는다 |

### 확인하지 않은 것은 쓰지 않는다

마이그레이션 번호, 파일명, 함수명, 테이블명, 티켓 번호를 **기억이나 추측으로 쓰지 않는다.** 실제 diff 나 파일에서 확인한 것만 쓴다. 확인할 수 없으면 그 식별자를 빼고 서술한다. "V121 컬럼 추가" 라고 썼는데 실제가 V123 이면 그 커밋은 이력에서 거짓말을 하는 셈이다.

### 좋은 예

```
주문 기간검색에서 마지막 날짜가 빠지던 문제

toISOString 을 쓰는 바람에 UTC 로 밀려서 31일 주문이 검색에 안 걸렸다.
KST 오프셋을 고정했다.
```

```
카탈로그 삭제된 주문도 목록에 표시
```

```
관리자가 파트너사 명의로 주문 대리 등록

SUPER_ADMIN 전용 메뉴로 분리했다. 파트너 쪽에는 대리 등록 표시가 뜨고
취소·재주문은 막힌다. 알림 메일은 보내지 않는다.
```

### 나쁜 예

```
[Feat] 관리자 대리 주문 등록 기능 — DB/메뉴/Lambda

관리자가 특정 파트너사 명의로 주문을 대신 등록할 수 있는 기반을 마련.
- orders.proxy_admin_id 컬럼 추가 (V121)
- SUPER_ADMIN 전용 대리 주문 메뉴 신설
- Lambda 3종에 대리 모드 분기 추가
```

태그, 엠대시 부연, 개조식 종결, 기계적 불릿, 확인 안 된 마이그레이션 번호가 한 번에 들어 있다.

### 여러 개로 나눌 때

- **기능 단위로 자른다.** 영역(백엔드/프론트)이 아니라 "무엇이 달라졌는가" 로 묶는다. 한 기능이 DB·API·화면에 걸쳐 있으면 그건 한 커밋이다.
- 나눈 결과를 커밋하기 전에 **목록으로 보여주고 승인을 받는다.**
- 형식을 일부러 흩뜨린다. 8개가 전부 같은 골격이면 그 자체가 티다.

### 커밋 직전 점검

- 제목에 `—` 가 있는가
- 모든 제목이 비슷한 길이인가
- 모든 본문이 불릿인가
- 종결어미가 전부 같은가
- 확인하지 않은 번호·이름이 들어갔는가

하나라도 해당하면 다시 쓴다.

### 커밋 실행은 별개

이 스킬은 **메시지를 어떻게 쓰는지** 만 다룬다. `git commit` 실행 여부는 사용자의 명시적 지시를 따른다. 메시지를 잘 썼다는 이유로 커밋하지 않는다.

## 2. 주석

코드가 이미 말하는 것을 반복하지 않는다. 주석은 **코드만 봐서는 알 수 없는 것** — 왜 이렇게 했는지, 무엇을 하면 안 되는지, 그 근거 — 를 남기는 자리다. Java/Kotlin/Swift/JS/Python 전부 같은 규칙.

### 규칙

1. 이모지 금지. 경고는 `주의:` 로 쓴다.
2. "무엇" 이 아니라 "왜" 만 쓴다.
3. 함정/하지마라는 `주의:` 한 줄로.
4. 결정에는 근거 한 조각을 붙인다 (날짜, 이슈 번호, changelog 번호 중 하나).
5. 짧게. 한 줄로 되면 트레일링 주석(`// ...`).
6. 한국어. 단정 설명체("~한다", "부르지 마라"). 확인 안 된 건 "추정" 이라 쓴다.

### 표본

의도 + 근거:

```java
// 관리자 refresh 만료 — 유휴 30분 sliding(2026-08-29, 직원 계정과 분리).
private int adminRefreshTokenExpirationMinutes = 30;
```

함정:

```swift
// 주의: 여기서 super openURL 을 부르지 마라 — isa-swizzle 로 무력화됨(2026-09-02 크래시 확정).
```

계산 근거 (숫자가 어디서 왔는지):

```css
/* 98px = 썸네일 110px − 좌우 margin 6px×2. 썸네일 폭을 바꾸면 같이 바꾼다. */
.badge { max-width: 98px; }
```

### 하지 말 것

- 이모지
- 코드 재진술 ("count 를 0으로 초기화")
- 죽은 주석 (주석 처리된 옛 코드, 지금 동작과 다른 설명)
- 근거 없는 TODO ("나중에 고치기")
- 작성자 서명, 날짜만 있고 내용 없는 헤더
